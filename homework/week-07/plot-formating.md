# STAT 432 Homework Plot Formatting

**Description:** Use this skill only to improve the formatting of plots for STAT 432 homework, and only when the student explicitly asks to use this skill. It applies to plots produced in R or Python; it does not authorize changes to the analysis or interpretation.

## Formatting rules

- **Margins:** Leave enough space for titles, tick labels, and legends so nothing is clipped. Keep margins balanced and avoid excessive empty space.
- **Titles:** Add a concise, informative title that describes what the plot displays. Use a subtitle only when it adds useful context.
- **Axes:** Label both axes clearly, show units where applicable, and use readable ticks with sensible scales and intervals.
- **Labels:** Use plain, specific wording and consistent capitalization. Make legends and annotations easy to read and avoid overlapping plotted data.
- **Colors:** Choose a restrained, high-contrast palette that remains distinguishable for common color-vision deficiencies and in grayscale. Do not rely on color alone to distinguish groups.
- **Sizes:** Set figure dimensions and text sizes so titles, labels, ticks, and legends remain legible at the intended display or export size. Apply equivalent settings in R or Python without requiring a particular plotting package.
